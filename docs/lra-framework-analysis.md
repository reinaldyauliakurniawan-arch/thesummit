## Architecture Overview

The Leadership Role Assessment is a 360° tool organized in **7 tiers**:

| Tier | Code | Name | Scope | Items |
|------|------|------|-------|-------|
| Universal Baseline | **PtP** | Permission to Play | Applies to ALL roles | 7 |
| Role 1 | **R1** | Individual Contributor | Leading Self | 6 |
| Role 2 | **R2** | Leading Others | Managing a team | 11 |
| Role 3 | **R3** | Leading Leaders | Managing managers | 7 |
| Role 4 | **R4** | Leading Function | Functional leadership | 8 |
| Role 5 | **R5** | Leading Business | P&L ownership | 7 |
| Role 6 | **R6** | Leading Enterprise | C-suite / CEO | 8 |
| **TOTAL** | | | | **54** |

### Rating Scale (1–5)

| Score | Label | Meaning |
|-------|-------|---------|
| 1 | Belum Memenuhi | Below minimum standard — needs immediate intervention |
| 2 | Di Bawah Ekspektasi | Below expectation — needs active development |
| 3 | Memenuhi | Meets expectation — acceptable performance |
| 4 | Melampaui | Exceeds expectation — performing well |
| 5 | Role Model | Sets the standard others should aspire to |

### Readiness Criteria

| AVG Score | Status | Meaning |
|-----------|--------|---------|
| ≥ 4.0 | Ready Now | Ready for next role within 0–3 months |
| 3.0–3.9 | Ready Soon | Ready within 3–12 months with clear development plan |
| < 3.0 | Not Ready | Needs serious intervention |

### Gate Scores

| Tier | Gate Score |
|------|-----------|
| PtP | ≥ 3.5 to proceed |
| R1–R6 | ≥ 4.0 = Ready Now, 3.0–3.9 = Ready Soon, < 3.0 = Not Ready |

### Assessment Perspectives (360°)

Every item is rated by: **Self, Atasan (Superior), Bawahan (Subordinate), Peer, Konsultan (Consultant)** → **AVG**

### PtP — PERMISSION TO PLAY (Universal Baseline)

> Gate Score: ≥ 3.5 to proceed. Items marked with ⭐ are gate items.

#### PtP.M1 ⭐ — Adopting Company Core Values / Integritas Dasar

**Category**: MINDSET
**Description**: Alignment with company values — no stealing, no lying, no tardiness, etc.

| Score | Behavior Description |
|-------|---------------------|
| 1 | Does not show alignment with company values |
| 2 | Alignment only when supervised |
| 3 | Consistent alignment in normal situations |
| 4 | Alignment even in difficult situations / under pressure |
| 5 | Becomes a role model of company values for others |

**Competency Measured**: Integrity under pressure — whether values hold when costly
**Observable Proving Behavior**: Choosing the ethical option when it has personal cost (reputation hit, lost resources, delayed progress)
**Observable Disproving Behavior**: Choosing self-beneficial option that violates principles when no one is watching
**Insufficient Evidence**: Choosing the ethical option when it also happens to be the most beneficial personally (confounded motivation)
